# Credits & Third-Party Notices

## Game
**Trivia Quest** — game design, code, and all illustrated artwork (backgrounds,
characters, avatars, UI, results art, brand mascot & logo) were created for this
project as original hand-built SVG vector art. Sound effects and music are
generated procedurally at runtime via the Web Audio API (no audio files).

(`assets/data/questions_source.json`).
